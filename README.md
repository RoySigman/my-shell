# my-shell
Simple shell implementation using C for Unix systems.

# The shell is capable of: 
  Running (most) Unix commands (ls, mkdir, echo, pwd, cat, ...).
  
  Running commands in the background (to run in the background, add a & after the command and its parameters).
  
  Showing history of previous commands.

# How to Use?
  Run commands like you are used to.
  
  If you want your command to run in the background, finish it with a &.
  
  If you want your command history, enter "history".
  
  To exit, enter "exit".
